# Gestion-Biblioteca-CNU0125

Math Library – Sistema de Gestión de Biblioteca para ‘Math For All’.

El centro de entrenamiento matemático Math For All cuenta con una gran cantidad de libros físicos de diferentes áreas académicas, principalmente matemáticas, química y física. Estos libros son utilizados tanto por docentes como por estudiantes para reforzar conocimientos teóricos, resolver ejercicios y apoyar el aprendizaje dentro y fuera del centro.
Sin embargo, actualmente no existe un sistema organizado para registrar y controlar los préstamos de dichos libros. Debido a esto, en muchas ocasiones los libros son prestados entre docentes o estudiantes y luego se desconoce quién los posee o en qué lugar se encuentran físicamente, ya sea en el local, en la casa de algún docente o prestados a un alumno. Esta situación provoca pérdida de tiempo al momento de buscarlos, desorganización y retrasos en las actividades académicas.
Por ello surge la necesidad de desarrollar un sistema de biblioteca en consola que permita registrar digitalmente los libros, controlar préstamos y devoluciones, consultar disponibilidad y facilitar la localización de cada ejemplar mediante distintos tipos de usuarios y permisos.
